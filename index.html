Tag Editor for Mac

Tag Editor is a handy spreadsheet for easy and quick setting, editing, and cleaning of ID3 tags. Generate missing tags and artwork automatically. Remove extra spaces and characters. Edit, copy, paste, find, and replace across multiple tags. Rename files in batch—automatic or manual—in one intuitive spreadsheet with full control.

Precise Tag Management

Supports ID3 tags for MP3, AIFF, WAV, FLAC. Handles MP4 tags for MP4 and M4A (Apple Lossless). Edit album, artist, artwork, title, track, year, BPM, key, genre, and more—manually or from online databases.

How It Works

Step 1: Import Files

Drag and drop audio files or folders into the spreadsheet. Instantly see all tracks with current tags, filenames, and attributes.

Step 2: Edit Tags

Click any cell to edit. Use find/replace, copy/paste, or auto-fill. Pull data from online databases or generate artwork on demand.

Step 3: Preview & Rename

Review all changes in real-time. Set batch rename rules based on tags. Clean extras like spaces automatically.

Step 4: Apply Changes

Hit apply to update tags and rename files. Changes saved directly—no exports or extra steps.

FAQ

What formats does Tag Editor support?

ID3 tags for MP3, AIFF, WAV, FLAC. MP4 tags for MP4 and M4A (Apple Lossless).

Can I edit artwork?

Yes. Download from online databases or drag in your own images. Resize and apply to batches.

Is there a limit to file batches?

No practical limit. Handles libraries of thousands efficiently on Mac.

Does it rename files?

Yes. Automatic batch renaming based on tags, or custom rules using any metadata.
